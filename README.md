Filmorate — это приложение для киноманов, которое объединяет функции кинообозревателя и социальной платформы. В этом проекте решается проблема поиска фильмов, общения с единомышленниками и получения персонализированных рекомендаций.

Помогает пользователям находить фильмы по своим вкусам. Дает возможность обсуждать кино с друзьями через лайки, отзывы и рекомендации. Объединяет любителей кино в одном месте.

Технологический стек:

- Java 21
- Spring Boot
- JDBC — для работы с базой данных
- Lombok
- JUnit 5 — для тестирования функциональности
- Maven — для сборки и управления зависимостями
- H2 Database — легковесная база данных для хранения данных в памяти

Управление данными:

- Создание, обновление и удаление фильмов, пользователей и режиссёров.
- Хранение: Данные хранятся в памяти с использованием H2.
- Поиск: Фильтры по названию и режиссёрам.
Социальные функции:

- проставить лайк фильму<br>
- оставить отзыв<br>
- добавить друзей (двухсторонняя дружба)<br>
- просмотр общих друзей<br>
- рекомендации на основе предпочтений<br>
- Эндпоинты API:<br>
<br>
- /users — управление пользователями<br>
- /films — работа с фильмами<br>
- /genres — жанры<br>
- /mpa — рейтинги MPA<br>
- /reviews — отзывы<br>
- /directors — режиссёры<br>
